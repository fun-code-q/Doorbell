Privacy Policy

Last updated: 2026-05-18

QR Doorbell is operated as a smart-doorbell service that lets a visitor "ring" an owner via a QR code, and lets the owner respond via the QRVault Android app. This page explains what we collect, why, and how long we keep it.

1. Data the guest provides

  • Optional free-text message (server-side stored as ciphertext sealed to the owner's public key — neither QR Doorbell nor Supabase can read it).
  • Approximate geolocation (lat / lon / accuracy) when the door has a geofence configured. Only used at the moment of ringing; stored on the ring row for audit and deleted with the ring (≤ 90 days).
  • A SHA-256-of-(server-secret-pepper, IP) hash. The raw IP never reaches the database. Hashes are unlinkable across pepper rotations (90 days).

2. Data the owner provides

  • Email + password for sign-in (Supabase Auth).
  • House name, door names, door GPS anchor when pinned.
  • Android FCM token for ring delivery.
  • Optional encrypted backup of the owner's libsodium private key, wrapped with an Argon2id-derived key. The passphrase never leaves the owner's device.

3. Retention

  • Ring records: deleted after 90 days (pg_cron daily).
  • Audit log: deleted after 180 days.
  • Rate-limit + idempotency rows: deleted within 1 hour.
  • Push delivery log: deleted after 60 days.

4. Subprocessors

  • Supabase Inc. (database + Realtime + Edge Functions).
  • Google Cloud (Firebase Cloud Messaging for push delivery).
  • Cloudflare (Turnstile bot protection).

5. Your rights (GDPR Articles 15–22)

  • Access / portability: from the QRVault app, Settings → About → Export my data.
  • Erasure: from the QRVault app, Settings → About → Delete account. Cascades across every row referencing your user id and removes you from auth.users.
  • Rectification: edit your profile in Settings.
  • Withdraw consent: revoke individual push tokens from Settings → Devices, or rotate any door's QR code at any time.

6. Contact

Use the GitHub repo's Private vulnerability reporting for security questions. For privacy questions, the maintainer contact is listed in CODEOWNERS at the repository root.
